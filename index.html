保存について（Pages版）

原稿はサーバーではなく、この端末のブラウザの中に保存されます。別の端末とは同期されませんので、大切な原稿はときどきバックアップを書き出してください。ブラウザのデータを消すと原稿も消えます。

GitHub Pagesで公開する手順
  1. 「このエディタのHTMLを保存」で index.html をダウンロードします（すでに公開中の場合は不要です）。
  2. GitHubのリポジトリに、その index.html を追加してコミットします。
  3. リポジトリの Settings → Pages で、公開するブランチを選んで保存します。
  4. 発行されたURLをスマホで開き、共有メニューから「ホーム画面に追加」するとアプリのように使えます。
